# 朱雀去AI化检查清单

> **用途**：写后流水线步骤4中，当检测到 AI 率偏高或用户要求降 AI 时，按此清单逐项检查并优化。
> **与 `references/朱雀AIGC检测对策.md` 配套**：本清单是操作手册，对策文件是原理说明。
> **适用场景**：网文正文（小说/剧本/散文均可），不适用于学术论文。

---

## 检查流程

### 一、诊断阶段（先定位再改）

- [ ] 按段落独立检测（朱雀 API `is_merge=false`），记录每个高风险段落的**具体原因**
- [ ] 统计全文 AI 率区间，确定优化策略（见下表）
- [ ] 运行 `scripts/fingerprint.py` 获取句长方差/段长/对话占比等客观指标
- [ ] 运行 `scripts/wordfreq.byte.pl` 获取 AI 味词密度

| AI率区间 | 策略 | 改动量 |
|---------|------|--------|
| >40% | 紧急救援 | 删除最高2-3章重写，其余批量改写 |
| 30-40% | 标准降AI | 重点改写前3个高风险章节 |
| 20-30% | 快速优化 | 只改标红高风险句，调段落顺序 |
| 15-20% | 精准微调 | 改10-15个高风险句，加2-3个具体案例 |
| <15% | 安全加固 | 预留5-10%安全边际，交叉检测 |

### 二、逐项检查（按六大指标）

#### 指标1：困惑度（用词预测性）
- [ ] 全文无连续 3 个以上高概率词组合
- [ ] 关键场景有非常规比喻/冷门形容词
- [ ] 无"如沐春风""阳光洒落""内心深处"等模板化表达
- **替换策略**：保留语义，换低概率表达。优先用具体动作/物件/感官描写

#### 指标2：突发性（句长与节奏）
- [ ] 句长方差 ≥ 110（真人区间下限）
- [ ] ≤12字短句占比 ≥ 7%
- [ ] ≤20字句子占比 ≥ 17%
- [ ] 相邻句子无连续相同主语开头（≥3句）
- [ ] 有碎片句/反问句/感叹句打破节奏
- **具体技法**：碎片句（"干就是了。"）、反问句、破折号中断、分号长句

#### 指标3：n-gram 模板（AI过渡词）
- [ ] 无"综上所述""由此可见""不难发现"等高危过渡词
- [ ] 无"不仅...而且""一方面...另一方面"等固定句式密集使用
- [ ] 任意200字内不超过1个正式过渡词
- [ ] 无成串连续AI过渡词（3个以上/段）
- **替换方向**：口语化（"说到这里""其实吧"）或具体化（直接说内容）

#### 指标4：语义连贯性（★★ 新增）
- [ ] 相邻段落无过于工整的承上启下句
- [ ] 无"完美总分总"结构（每段都总结主题）
- [ ] 每3-4段有1句闲笔/题外话/个人联想
- [ ] 段落结尾不是每段都总结
- [ ] 有倒叙/插叙/多观点碰撞
- **闲笔示例**："说到这个，我突然想起...""（窗外有人在吵架）""反正事情就是这样。"

#### 指标5：空洞度与细节比例（★★ 新增）
- [ ] 每个抽象观点后紧跟1个具体案例/数据
- [ ] 无连续2句以上纯抽象概括
- [ ] 有数字（百分比/时间/数量/编号）
- [ ] 有感官细节（颜色/声音/气味/触感）
- [ ] 有个人经历/观察（"我之前...""这让我想起..."）
- **替换示例**：
  - ❌ "产生了重要影响" → ✅ "焦虑检出率高42%"
  - ❌ "具有广阔前景" → ✅ "去年10帧，今年60帧"

#### 指标6：情感修辞波动（★★ 新增）
- [ ] 无连续3段相同情感色调（全冷/全热/全中性）
- [ ] 有不确定性表达（"可能""也许""我猜""说不好"）
- [ ] 无绝对化表达密集使用（"必然""完全""显著"）
- [ ] 排比不超过2组连续使用
- [ ] 有修辞多样性（反讽/通感/自嘲等，不只用排比比喻）
- **通感示例**："尖锐的甜味""温暖的灰色"

### 三、小说/剧本特殊检查

- [ ] 每个主要角色有1-2个专属口癖/说话习惯
- [ ] 对话有打断、重复、口头禅、语无伦次
- [ ] 对话中穿插动作（喝水/看手机/走神）
- [ ] 紧张段落用短句，舒缓段落用长句，节奏有变化

### 四、验证阶段

- [ ] 改写后重跑 `scripts/fingerprint.py`，指标落入真人区间
- [ ] 改写后重跑 `scripts/wordfreq.byte.pl`，无 ❌ 超标
- [ ] 通读改动段落，确认无碎句堆砌/干瘪空洞/语义断裂
- [ ] 安全边际：AI率比目标值低5%（要求≤15% → 控制在≤10%）
- [ ] 用维普AI交叉检测（如可用）

### 五、防过度提醒

- [ ] 改动保持自然，不是面目全非
- [ ] 优先用具体动作/物件/对话替换，不机械删除
- [ ] 通顺优先于方差——通顺与方差冲突时，通顺优先
- [ ] 铁律三分档的上限是上限不是目标——不刻意凑满
- [ ] 不用通用AI改写AI内容（AI改AI仍然是AI）
