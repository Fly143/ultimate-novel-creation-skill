# 功能模块归属映射表（多Agent版）

> **设计原则**：模块文件**不物理复制**，统一存放在仓库根 `modules/`（单一事实源）。
> 本表定义每个模块的**逻辑归属**：谁读、何时读。部署时可参照本表决定各 Agent 的读取权限/挂载范围。
> 标记说明：🟢 专属（仅该角色读）｜🟡 共享（多角色读）｜🔵 主编调度（主编决策用）

## 共享资源归属

| 资源 | 归属 |
|---|---|
| `references/`（创作理论/技巧/风格） | 写手（写作时）+ 审核官（F项对照，如 `风格技巧详解.md`、`高级写作技巧-整合版.md`） |
| `templates/`（人设卡/大纲/章节模板等） | 按对应模块跟随（设定师为主）；`章节质量检查清单.md`→审核官；`节奏诊断报告.md`→审核官 |
| `memory-system/`（圣经五件套模板） | 写手（归档）/ 设定师（初始化）/ 修复师（18F） |
| `scripts/fingerprint.py`（文风指纹） | 设定师（初始化时按用户要求跑） |

## 部署提示

- **单 Agent 挂载**：只给该 Agent 挂它 🟢 专属模块 + 🟡 共享模块中它负责的部分，🔵 主编模块不给（防越权）。
- **记忆三权分立**（03_18）：写入权按触发方划分——每章归档=写手，手动编辑=设定师，修复跑偏=修复师。任何 Agent 不得越权改写圣经文件。
