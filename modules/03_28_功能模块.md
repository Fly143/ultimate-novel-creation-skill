# 功能模块 28：轻量直出（一次性短文/推文，旁路项目制）

> **功能编号**：28
> **功能定位**：用户要写几千字短文/公众号推文等一次性产出内容时，跳过立项/规划/记忆系统，直接产出正文，写后仅跑去AI化（朱雀六指标），不跑 G/D 连贯性（无跨章可比）。产物默认不存档，可按用户意愿存档为项目。
> **触发**：00协议「轻量直出意图」（说"写篇推文""写篇短文""直接出正文""短文直写""公众号文章"等，且未指定建项目/分章/分段）。

---

## 一、与常规流程的差异（明确不做什么）

| 常规长篇/短篇流程 | 轻量直出 |
|---|---|
| 03_01 立项 → 03_04 规划 → 记忆系统初始化 | **全跳过** |
| 03_06 子代理写作（带字数脚本硬校验） | 直接产出（主代理或子代理均可，无硬字数门槛） |
| 03_26 写后流水线（G/D/朱雀全量 + 圣经维护） | **仅跑朱雀六指标去AI化**（4.1d），不跑 G 逻辑因果 / D 连贯性 / 圣经更新 |
| 产物存 `[书名]/正文/` 项目结构 | 直接输出正文给用户；可选存档 |

---

## 二、执行流程

```
1. 确认需求（轻量引导，不立项）：
   - 主题/核心信息（推文要点、面向读者、语气风格）
   - 目标字数（可选；几千字短文不强制卡字数，写完差不太多即可）
   - 是否要分章节：直出默认不分章节，整篇一段式输出
2. 产出正文：
   - 按用户给的主题/风格直接写，字数灵活（如 800-5000 字自由发挥，不卡 2000 下限）
   - 允许主代理直接写或委托子代理写（delegate_task 可用时优先子代理，保持去AI化质量）
   - **动笔前加载写作技巧（同长篇 03_06 的通用质量知识，但只取推文适用的，不加载小说叙事类技巧）**：
     - **必读**：`references/高级写作技巧-整合版.md`（去AI化写作规则：反AI铁律/模板词黑名单/人味毛刺/文字质量红线）+ `templates/单章结构模板.md`（开篇钩子/铺垫/高潮/收尾四段式结构，推文也适用）
     - **不加载小说专用技巧**（黄金开篇/爽点设计/打斗指南/冲突反转/风格模仿等——这些是长篇叙事结构，推文一次性产出用不到）
     - 不读文风设定（直出无项目无文风文件，按用户说的风格走）；不读叙事趋势/细纲（无项目）
3. 写后去AI化（仅朱雀六指标，4.1d 节）：
   - 主代理读 references/朱雀AIGC检测对策.md 指标4/5/6 写后优化判定点，通读全文
   - 按 语义连贯性/空洞度/情感修辞 三项各输出 ✅/🟡/🔴 + 段落引用 + 修改建议
   - 任一 🔴/🟡 → 按 4.3 第4条（朱雀对策）优化；全 ✅ → 不触发额外修复
   - ⚠️ 防过度：改最少原则，本就达标标 ✅ 即可，不硬改
   - 客观指纹脚本（fingerprint.py / wordfreq）可选跑：直出短文样本少，主观目测为主；宿主有 python/perl 则跑一次佐证
4. 交付：
   - 直接把正文交给用户（不建项目目录、不写 .done）
   - 询问：「是否存档为项目以便后续修改/续写？」
     - 是 → 走 03_27 导入流程反向建项目（或 03_01 立项），把本文明文纳入
     - 否 → 结束
```

## 三、铁律与边界

- **不触达记忆系统**：直出不读不写 5 圣经/摘要，无跨章状态。
- **不跑 G/D**：逻辑因果(G)与连贯性(D)依赖历史章节比对，直出无前文，跳过（用户要严谨逻辑审可改走短篇分段模式）。
- **字数不硬卡**：直出短文以"写完即发"为目标，字数灵活；仅当用户显式给目标字数时尽量贴近。
- **去AI化必跑**：朱雀六指标是直出唯一质量门禁（推文也怕 AI 味），不可省略。
- **delegate_task 不可用**：按 03_26 步骤3 前置检查降级规则——主代理自审（此处即主代理直接写+自跑去AI化），注明 Fallback。
- **与短篇分段模式区分**：分段模式是"建了项目、按段写、整篇审"；直出是"完全不建项目、一次出、只去AI化"。用户说"推文/短文直写"走本模块，说"写个短篇/按段写"走 03_04 分段路径。
