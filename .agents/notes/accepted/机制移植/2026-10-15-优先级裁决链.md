# ADR：优先级裁决链（P0-1）

- 状态：accepted
- 类别：流程治理
- 日期：2026-10-15

## problem

用户口头要求与硬门禁（朱雀三态、`.done` 闭环、记忆系统一致性）冲突时，写作代理行为不确定：要么盲目服从丢掉门禁，要么死守门禁顶撞用户。

## decision

`用户要求 > 硬门禁 > 项目约束 > skill 流程 > reference 建议`；例外处置固定：告知后果 + 书面确认，默认不跳过朱雀；裁决链置 `modules/00_强制执行协议.md` 顶部为最高口径。

## validation

- 00 顶部裁决链 + `system_prompt.md` / README 三处同步（commit `04e517b`）
- `audit.ps1 -LintOrder` 守护写后顺序锚点，防止下游文档写出第二套顺序与裁决链打架
