# 章节任务书模板（写入 `[书名]/设定/细纲/第NNN章_细纲.md` 头部区块）

> 用途：动笔前的唯一任务来源。四段缺任一段 → 禁止开写；`MUST DO` 至少 1 条「（必落）」节拍；写后未全勾 → 本章判未完成。
> 作者可在开写前改任意字段，改后按改后内容开写，不退回前置阶段。

```markdown
## 章节任务书

### TASK 本章任务
（一句话：本章要完成的叙事任务）

### GOAL 原子目标
（1 条主目标 + 可选 1-2 条次目标；必须是可观察结果）

### EXPECTED OUTCOME 交付物与成功标准
- 交付物：正文（≈N 字，见字数带）
- 成功标准：① 必落节拍全覆盖 ② 主目标有可见结果 ③ 无未回收新增伏笔

### MUST DO 必须完成
- [ ] 节拍1（必落）
- [ ] 节拍2（必落）

### MUST NOT DO 禁止
- 不得引入未在本任务书登记的新人物/新设定
- 不得提前揭示未到揭示章的作者真相条目
- 不得使用禁词表（`references/` 规则集）
- 不得为凑字数注水

### CONTEXT 信息索引（只列索引，不粘贴全文）
- 前文接续：第 N-1 章摘要
- 设定：`设定/[书名]_人设卡.md#相关角色`、`[书名]_世界观设定.md#相关规则`
- 记忆：`记忆系统/圣经/伏笔清单.md`（本章应推进/回收：Fxxx）
- 风格：`[书名]_文风设定.md`

### 信息源纪律
当前任务提示是唯一信息来源。未提供的信息禁止自行补充或推断；
确有必要新增 → 先停下询问作者，不得自行决定。

### 字数带
作者区间（若有）：`字数范围：2000-2600` → 结果 `band_source = author`
否则用默认带 → `band_source = default`

### 状态
- [ ] 任务书已确认（作者或规则确认）
- [ ] 已开写
```

## 校验口径（与 `scripts/check-done.{py,ps1}` 同源 `scripts/check-done-rules.json`）

| 检查 | 时机 | 不过处置 |
|---|---|---|
| 四段 `TASK`/`GOAL`/`MUST DO`/`CONTEXT` 齐 | 写前 | 输出缺项清单，阻断开写 |
| `MUST DO` ≥1 条 `（必落）` 项 | 写前 | 同上（不允许边写边想） |
| `（必落）` 项全部 `[x]` | 写后闭环 | 本章判未完成，不得写 `.done_chapter` |
| 脚本核验 | 写后 | `check-done --require-task-sheet` / `-RequireTaskSheet` → 缺则 exit1 |
