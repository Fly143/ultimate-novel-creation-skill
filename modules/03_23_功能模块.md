### 23. 作品拆解分析

**功能**：从已有作品中提取人物性格、写作风格与剧情结构，**落盘为可复用的拆文库素材库**，用来指导自己的创作。

**两种输入模式，自动判断**：

| 模式 | 用户怎么说 | LLM 怎么做 |
|------|-----------|-----------|
| 知识库模式 | 「分析《诡秘之主》的克莱恩」「萧炎是什么性格」 | 从训练数据中调用对作品/人物的记忆 |
| 原文模式 | 贴一段原文 + 「分析这个人物」「提取这段的风格」 | 从提供的文本中逐句分析 |

不需要手动选择模式——你说人话，我自动判断。

## 子功能 A：人物性格提取

### 输入
- 知识库模式：书名 + 人物名
- 原文模式：包含该人物的原文段落（越长越准）

### 分析维度

| 维度 | 分析什么 | 有什么用 |
|------|---------|---------|
| **性格标签** | 不是「勇敢善良」这种废话，是「表面隐忍内心暴烈」「精明算计但对自己人无条件」这种能直接写进人设卡的 | → 功能 3 人设卡 |
| **性格矛盾** | 真实人物都有矛盾：「想被认可又拒绝亲近」「渴望力量却厌恶杀戮」 | → 功能 17 OOC 基准 |
| **行为模式** | 面对危机 / 面对弱者 / 面对利益 / 面对感情时，TA 分别怎么做？ | → 功能 6 写作参考 |
| **说话风格** | 口头禅、句式长短、敬语习惯、说与不说的习惯 | → 功能 9 对话场景 |

## 子功能 B：风格提取

### 输入
- 知识库模式：书名（说「分析《凡人修仙传》的写作风格」）
- 原文模式：原文段落（越长越准，至少 2000 字）

### 分析维度

| 维度 | 分析什么 | 有什么用 |
|------|---------|---------|
| **句式特征** | 平均句长？短句多还是长句多？白描还是铺陈？修饰多不多？ | → 功能 6 风格约束 |
| **节奏模式** | 多久放一个爽点？铺垫几章爆发？日常和战斗的比例？ | → 功能 6 章节节奏 |
| **描写偏好** | 环境描写多还是心理描写多？打斗是写意还是写实？感官描写用了哪几种？ | → 功能 10 打斗场景 |
| **对话风格** | 对话占比？对话长度？对话推动剧情还是塑造人物？ | → 功能 9 对话场景 |
| **叙事距离** | 上帝视角还是贴身视角？旁白多不多？内心独白多少？ | → 功能 6 叙事角度 |

## 子功能 C：全书拆解（拆文库）

**功能**：把整本（或大半本）爆款拆成**可复用的素材库**——不只是报告，而是以后写作时能直接调用的模块。

### 输入
- 知识库模式：书名（说「拆解《XXX》」「拆文库《XXX》」）
- 原文模式：贴入全书/大部头原文（拆解范围自动按章节切分）

### 拆文库目录结构

```
[书名]/设定/拆解/{作品名}/
├── 拆解报告.md          ← 总览：题材定位/卖点/结构骨架/黄金三章拆解
├── 情节节点.md          ← 主线/支线/钩子位置/高潮分布/转折点（→ 写作时参考节奏与钩子）
├── 情绪模块.md          ← 爽点类型/情绪曲线/可复用桥段（→ 功能 7 爽点设计参考）
├── 人物模块.md          ← 主角/配角/反派的人物模型与弧线（→ 功能 3 人设参考）
├── 文风.md              ← 句式/节奏/描写偏好/对话风格（→ 功能 6 风格约束）
└── 素材引用说明.md      ← 哪些模块可在新书写作时调用、怎么调
```

### 各文件要点

| 文件 | 内容要点 |
|------|---------|
| `拆解报告.md` | 题材与卖点一句话；结构骨架（三幕/五段）；黄金三章各章职责与钩子 |
| `情节节点.md` | 按章记录：事件 / 钩子 / 高潮 / 转折 / 伏笔埋点——形成可对照的节奏图谱 |
| `情绪模块.md` | 每类爽点（打脸/逆袭/升级/收获）的铺垫-爆发-反馈写法；情绪曲线形态（爬坡/波浪/断层） |
| `人物模块.md` | 每个主要角色的：定位 / 核心欲望与恐惧 / 弧线变化 / 可迁移到新书的"人物模型" |
| `文风.md` | 与子功能 B 同维度，但基于全书样本更精确 |
| `素材引用说明.md` | 明确每个模块对应新书写作时的哪个功能/步骤、如何引用路径 |

### 使用方式（新书写作时调用）

- 写作（03_06）遇到同类桥段 → 读 `情绪模块.md` 对应条目做参考（不照抄情节）
- 设计人设 → 读 `人物模块.md` 迁移人物模型
- 控制节奏 → 对照 `情节节点.md` 的高潮间隔
- 风格统一 → 套用 `文风.md` 的风格配方（结合 03_16 修订）

> 拆库不是抄：提取的是创作思路、性格模型与结构规律，不是情节与设定本身。引用时需改写融合进新书。

## 注意事项

- **知识库模式精度有限**：LLM 对作品细节的记忆可能有偏差，重要创作建议用原文模式
- **原文越长越准**：2000 字以上能看出风格规律，500 字只能做粗略判断；全书拆解建议原文模式贴入足够样本
- **人物拆解尽量贴原文**：二手的人物分析（百科/书评）容易简化扁平化人物
- **拆解不是抄**：提取的是创作思路和性格模型，不是情节和设定；拆文库引用时需改写融合
