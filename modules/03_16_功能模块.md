### 16. 修订优化

**功能**：修订已写内容、优化文字质量。修订后自动同步记忆系统，确保圣经文档与正文一致。
**参考资源**：`references/高级写作技巧-整合版.md`
**模板**：`templates/章节质量检查清单.md`
**记忆系统**：修订完成后，检查并同步受影响的 圣经 文档（人物弧线 / 剧情时间线 / 伏笔清单 / 角色数据库 / 故事圣经）

---

**执行流程**：

```
=== 修订优化阶段 ===
1. 确认修订对象（单章/多章/全书）
2. 读取修订内容
3. 读取 `references/高级写作技巧-整合版.md` 和 `templates/章节质量检查清单.md`
4. 按 `references/高级写作技巧-整合版.md` 的文字质量与反AI检查项执行检查：
   - 文字质量：错别字、病句、重复用词、冗余描写
   - 情节逻辑：前后矛盾、时间线错误、因果关系
   - 人物一致性：性格偏移、行为逻辑、对话风格
   - 节奏问题：拖沓、过快、节奏失衡
   - 去AI味（用户要求去AI味时）：按 `references/高级写作技巧-整合版.md` 第十三节「去AI味改写规范」执行——改最少效果最大、删除比例分级（轻≤15%/中≤25%/重≤35%）、`[需复核]` 标注、保留创作意图；替换方向优先用铁律三附表「人味词」的具体动作/物件/口语写法，禁止机械删除
   - **检测器友好改写**：按 `references/高级写作技巧-整合版.md` 第十四节「检测器友好改写」执行——打破判断句、打破总分总、降低刻意复杂度；**若需获得"人工特征"，提示用户真人介入改写 20-30% 关键句**（AI 自改无法达到）
5. 生成修订报告，保存至 [书名]/报告/修订记录.md
6. 提供修订后的内容

=== 修订后记忆同步（如记忆系统已初始化） ===
7. 【检查影响范围】确定修订影响了哪些维度：
   - 人物变化 → 更新 人物弧线.md 中角色状态
   - 情节变化 → 更新 剧情时间线.md 中事件描述
   - 伏笔变化 → 更新 伏笔清单.md 中伏笔状态
   - 设定变化 → 更新 故事圣经.md 中世界观描述
   - 角色状态变化 → 同步 角色数据库.md（出场/退场/持有物变动）
8. 【执行同步】逐项更新对应圣经文档
9. 【输出】修订同步报告
```

**半自动修订的保存与重生成纪律（P3-23/AN-6）**：
1. **保留既有产物**：修订/重生成提交时必须保留已有正文、其他章节、归档规划与已存报告；旧数据、不完整草稿**不得覆盖**保存结果
2. **空建议也允许重生成**：未填修正建议同样执行重新生成（按当前内容重跑本模块检查项），不得因缺建议而拒绝
3. **失败给具体原因**：生成或保存失败 → 输出具体原因（缺哪份输入/哪个文件不可读/哪步校验不过），**从保存进度继续**，用户已输入的内容不得丢弃
4. 修订完成后仍走既有：记忆同步 +（涉及正文改动时）`text_guard` retcon 留痕

**输入信息**：
- 修订对象（单章/多章/全书）
- 修订内容（文件路径或内容）
- 重点关注问题（文字质量/情节逻辑/人物一致性/节奏问题/去AI味）（可选）

**输出**：
- 修订记录：`[书名]/报告/修订记录.md`
- 修订后的内容（直接反馈给用户）
