### 4. 情节大纲 

**功能**：生成整体框架、规划章节安排、爽点分布，可选同步到记忆系统
**参考资源**：`` `references/爽文创作理论.md` ``
**模板**：`templates/情节大纲模板.md`、`templates/章节规划表.md`、`templates/百万字规划模板.md`
**记忆系统**：支持自动同步剧情逻辑到 记忆系统/圣经/剧情时间线.md

**执行流程（强制按顺序执行）**：

```
=== 情节大纲生成阶段 ===
1. 确定故事结构和阶段划分
2. 规划主线冲突和支线剧情
3. 设计爽点分布节奏
4. 规划伏笔埋设和回收
5. 规划主角成长轨迹（基于世界观设定和人物设定，设计主角从起点到终点的能力/心性/关系成长路径）
6. 保存情节大纲文件：[书名]/设定/[书名]_情节大纲.md

=== 分卷大纲生成 ===
6.1 基于主线大纲的阶段划分，逐卷展开分卷大纲：
    - 卷边界按 `templates/百万字规划模板.md` 的分卷口径（卷压缩按每50章，与 03_18-D2/03_26 步骤5 一致）
    - 标注卷内核心冲突线和预计高潮点
    - 标注本卷出场角色（新角色+旧角色回归）
    - 标注本卷暗线推进节点
    - 标注主角本卷能力/心性/关系的成长里程碑
6.2 逐卷预登记角色到 [书名]/记忆系统/圣经/角色数据库.md：
    - 填写「按卷预设出场角色」表（角色名+身份+本卷出场范围+预计首次出场章节）
    - 新角色先入「待使用角色（储备池）」，标注预计出场卷号
6.3 保存分卷大纲：[书名]/设定/[书名]_分卷大纲.md

=== 章节规划表生成（强制执行·即章节大纲） ===
7. 基于情节大纲和分卷大纲，生成逐章规划：
   - 每章内容概要
   - 字数目标
   - 章节类型（高潮章/伏笔回收章/过渡章/标准章，与 03_06 步骤1 判定表一致）
   - 爽点类型
   - 出场角色
   - 场景
   - 冲突目标
   - 状态标记
   - **⚠️ 滚动生成策略（防退化）**：**首次仅生成前 30 章的章级规划**（逐章一行，完整字段）。不一次性生成全书——全书一次生成会因上下文过长退化为"卷级梗概"，导致后续章无章级概要可用。后续批次由「工作流E：续生成」按需滚动补齐（详见下文）。
8. 保存章节规划表：[书名]/设定/[书名]_章节规划表.md，并在文件**开头第一行**写入批次标记：
   - 格式：`> 已规划批次：第1-30章（每批默认30章滚动生成，可指定）`
   - 续生成后更新该行为最新批次上限（如 `第1-60章`）

=== 工作流E：续生成下一批章节（滚动补齐，批次大小可指定） ===
**触发条件**（任一）：
- 自动：03_06 写前发现「本章在规划表中缺失 / 该行退化为卷级梗概（无章级内容概要、无冲突目标）」时，主代理先调用本流程补出本批（自动触发时 **N 固定取默认30**，不猜测用户意图）
- 手动：用户说「扩展规划」「规划续写」「续规划」，可带批次大小参数：
  - 「扩展规划」/「规划续写」/「续规划」 → N = 30（默认）
  - 「扩展规划50章」/「规划续写100章」/「续规划N章」 → N = 用户指定值

**批次大小 N**：本次续生成生成的章数。**默认30**；用户显式指定时以用户为准（如50/100）。自动兜底触发一律用30。

**执行步骤**：
1. 读取分卷大纲 `[书名]/设定/[书名]_分卷大纲.md` —— 以卷边界为约束，确认本批 N 章落在哪卷、该卷核心冲突线与暗线节点
2. 读取已写章节进度：最新一章编号 N0 + 其摘要/圣经当前状态快照，确认"从哪续、当前剧情走到哪"
3. 读取现有规划表批次标记，确定续生成区间（如已规划至30章 → 本批生成第31章 ~ 第30+N章）
4. 基于分卷大纲 + 当前进度，生成本批 N 章章级规划（字段同第7步，逐章一行完整字段）
5. **仅追加，不重写**：将新 N 行追加到规划表已有内容之后；**严禁覆盖/改动已写章节的规划行与状态**
6. 更新开头批次标记行为新上限（如 `第1-60章`）
7. 若全书目标章数已规划完（续生成区间超出总篇幅规划）→ 提示「章节规划表已全部规划至第X章，无需续生成」

=== 记忆系统同步（如已初始化） ===
9. 【记忆系统检查】检查记忆系统是否已初始化：
   - 检查路径：[书名]/记忆系统/ 目录是否存在
   - 检查文件：[书名]/记忆系统/圣经/剧情时间线.md 是否存在
   - 如果已初始化，执行步骤9.1-9.3；如果未初始化，跳转到步骤10

9.1 【自然语言同步】将大纲内容写入剧情时间线文档：
    - 读取刚生成的情节大纲：[书名]/设定/[书名]_情节大纲.md
    - 读取章节规划表：[书名]/设定/[书名]_章节规划表.md
    - 提取并追加到 [书名]/记忆系统/圣经/剧情时间线.md：
      * 主线时间线：将大纲中的主要事件按章节顺序填入（加标签[主线]/[支线X]/[交叉]）
      * 支线状态：创建活跃支线状态表
      * 伏笔清单：同步到 [书名]/记忆系统/圣经/伏笔清单.md
    - **★ 同步更新角色数据库**：[书名]/记忆系统/圣经/角色数据库.md
      * 根据大纲填写「角色重要性层级」表（主角/核心配角/关键角色/次要/单元/背景）
      * 根据大纲填写「按卷预设出场角色」表（每卷的角色配置，含预计出场章节范围）
      * 将大纲中提到的新角色添加到「待使用角色（储备池）」——后续写前单元案细纲时从此池迁入正式表
      * 仅登记角色名+身份+预计出场卷号，不填详细人设（留给单元案细纲阶段展开）
      * 注意：不需要转换为 JSON；LLM 直接读写 markdown 表格
    - **[书名]/设定/[书名]_角色储备表.md**：从大纲/章节规划表提取所有已命名角色，同步登记到此文件作为角色池索引

9.2 【更新】添加到进度看板：
    - 标记任务完成：[x] 03_04完成大纲后更新 剧情时间线.md
    - 保存：[书名]/设定/进度看板.md

9.3 【输出】剧情逻辑同步完成报告：
    ```
    ✅ 剧情逻辑已同步到记忆系统

    【已同步】
    ✓ 主线事件已写入 剧情时间线.md
    ✓ 支线已创建独立追踪
    ✓ 伏笔已同步到 伏笔清单.md

    【下一步】
    1. 使用03_05模块生成黄金开篇，自动创建首章摘要
    2. 03_06（单章写作）会持续维护剧情时间线和伏笔清单
    ```

10. 完成情节大纲流程
```

**输入信息**：
- 故事主线（核心目标、核心冲突）
- 结构选择（三幕式/英雄之旅/起承转合/多线并行）
- 爽点类型偏好

**输出**：
- 情节大纲：`[书名]/设定/[书名]_情节大纲.md`
- 章节规划表：`[书名]/设定/[书名]_章节规划表.md`
- 剧情逻辑同步报告（如记忆系统已初始化）

**记忆系统集成说明**：

| 功能 | 实现方式 | 触发时机 |
|------|---------|---------|
| **剧情逻辑同步** | 自然语言同步到 剧情时间线.md | 大纲生成完成后自动执行 |
| **上下文关系更新** | 解析章节规划并更新上下文 | 章节规划表生成后自动执行 |
| **伏笔追踪初始化** | 将伏笔规划同步到记忆系统 | 大纲生成后自动执行 |
| **剧情进展追踪** | 每章后自动更新剧情状态 | 每章创作后自动更新（03_06模块） |

**注意事项**：
1. 记忆系统同步是可选的，只有在记忆系统已初始化时才会执行
2. 如果记忆系统未初始化，大纲生成会正常完成，只是不会同步到记忆系统
3. 同步后的剧情逻辑会在每章创作前自动提供当前剧情进展
4. 每章创作后会自动更新剧情状态、伏笔回收情况
5. 如果后续有剧情调整，可以通过03_18模块手动更新剧情逻辑
