# 朱雀去AI化检查清单

> **用途**：写后流水线步骤4中，当检测到 AI 率偏高或用户要求降 AI 时，按此清单逐项检查并优化。
> **与 `references/朱雀AIGC检测对策.md` 配套**：本清单是操作手册，对策文件是原理说明。
> **适用场景**：网文正文（小说/剧本/散文均可），不适用于学术论文。

---

## 检查流程

### 一、诊断阶段（先定位再改）

- [ ] 按段落独立检测（朱雀 API `is_merge=false`），记录每个高风险段落的**具体原因**
- [ ] 统计全文 AI 率区间，确定优化策略（见下表）
- [ ] 运行 `scripts/fingerprint.py` 获取句长方差/段长/对话占比等客观指标
- [ ] 运行 `scripts/wordfreq.byte.pl` 获取 AI 味词密度

> **⚠️ 下表仅为「AI创作特征」残留量的参考分档，不是流水线闭环验收。**  
> **v9.6.0 硬验收以三态「人工创作特征 > 疑似AI创作特征」为准**（见下方★人工为主协议）。百分比高≠流程可跳过人工证据包；百分比低≠可以宣称检测通过。

| AI率区间（参考） | 策略（参考） | 改动量（参考） |
|---------|------|--------|
| >40% | 紧急救援 | 删除最高2-3章重写，其余批量改写 |
| 30-40% | 标准降AI | 重点改写前3个高风险章节 |
| 20-30% | 快速优化 | 只改标红高风险句，调段落顺序 |
| 15-20% | 精准微调 | 改10-15个高风险句，加2-3个具体案例 |
| <15% | 安全加固 | 预留5-10%安全边际；**最终验收仍看人工是否 > 疑似** |

### 二、逐项检查（按六大指标）

#### 指标1：困惑度（用词预测性）
- [ ] 全文无连续 3 个以上高概率词组合
- [ ] 关键场景有非常规比喻/冷门形容词
- [ ] 无"如沐春风""阳光洒落""内心深处"等模板化表达
- **替换策略**：保留语义，换低概率表达。优先用具体动作/物件/感官描写

#### 指标2：突发性（句长与节奏）
- [ ] 句长方差 ≥ 90（基本达标线；真人区间下限110，但90-110属正常边缘，**勿为凑方差机械切句**）
- [ ] ≤12字短句占比 ≥ 7%
- [ ] ≤20字句子占比 ≥ 17%（仅差1-2个百分点即视为达标，不强制）
- [ ] 相邻句子无连续相同主语开头（≥3句）
- [ ] 有碎片句/反问句/感叹句打破节奏
- **具体技法**：碎片句（"干就是了。"）、反问句、破折号中断、分号长句
- **⚠️ 容错**：方差≥90即达标，仅<90且长句主导才需打散；占比边缘值（差1-2个百分点）直接放行，避免反复修改导致碎句

#### 指标3：n-gram 模板（AI过渡词）
- [ ] 无"综上所述""由此可见""不难发现"等高危过渡词
- [ ] 无"不仅...而且""一方面...另一方面"等固定句式密集使用
- [ ] 任意200字内不超过1个正式过渡词
- [ ] 无成串连续AI过渡词（3个以上/段）
- **替换方向**：口语化（"说到这里""其实吧"）或具体化（直接说内容）

#### 指标4：语义连贯性（★★ 新增）
- [ ] 相邻段落无过于工整的承上启下句
- [ ] 无"完美总分总"结构（每段都总结主题）
- [ ] 每3-4段有1句闲笔/题外话/个人联想
- [ ] 段落结尾不是每段都总结
- [ ] 有倒叙/插叙/多观点碰撞
- **闲笔示例**："说到这个，我突然想起...""（窗外有人在吵架）""反正事情就是这样。"

#### 指标5：空洞度与细节比例（★★ 新增）
- [ ] 每个抽象观点后紧跟1个具体案例/数据
- [ ] 无连续2句以上纯抽象概括
- [ ] 有数字（百分比/时间/数量/编号）
- [ ] 有感官细节（颜色/声音/气味/触感）
- [ ] 有个人经历/观察（"我之前...""这让我想起..."）
- **替换示例**：
  - ❌ "产生了重要影响" → ✅ "焦虑检出率高42%"
  - ❌ "具有广阔前景" → ✅ "去年10帧，今年60帧"

#### 指标6：情感修辞波动（★★ 新增）
- [ ] 无连续3段相同情感色调（全冷/全热/全中性）
- [ ] 有不确定性表达（"可能""也许""我猜""说不好"）
- [ ] 无绝对化表达密集使用（"必然""完全""显著"）
- [ ] 排比不超过2组连续使用
- [ ] 有修辞多样性（反讽/通感/自嘲等，不只用排比比喻）
- **通感示例**："尖锐的甜味""温暖的灰色"

### 三、小说/剧本特殊检查

- [ ] 每个主要角色有1-2个专属口癖/说话习惯
- [ ] 对话有打断、重复、口头禅、语无伦次
- [ ] 对话中穿插动作（喝水/看手机/走神）
- [ ] 紧张段落用短句，舒缓段落用长句，节奏有变化

### 四、验证阶段

- [ ] 改写后重跑 `scripts/fingerprint.py`，指标落入真人区间（或落入缓冲带：方差≥90、占比仅差1-2个百分点）即放行，勿为凑边缘值反复改
- [ ] 改写后重跑 `scripts/wordfreq.byte.pl`，无 ❌ 超标
- [ ] 通读改动段落，确认无碎句堆砌/干瘪空洞/语义断裂
- [ ] 安全边际：AI率比目标值低5%（要求≤15% → 控制在≤10%）（**仅参考分档**）
- [ ] **人工为主（硬验收）**：朱雀三态「人工创作特征」>「疑似AI创作特征」
- [ ] **语义边界**：`.done_zhuque` 已写 ≠ 检测已通过；缺标记必补步骤，有标记仍可能未达标
- [ ] 用维普AI交叉检测（如可用）

### 五、防过度提醒

- [ ] 改动保持自然，不是面目全非
- [ ] 优先用具体动作/物件/对话替换，不机械删除
- [ ] 通顺优先于方差——通顺与方差冲突时，通顺优先
- [ ] 铁律三分档的上限是上限不是目标——不刻意凑满
- [ ] 不用通用AI改写AI内容（AI改AI仍然是AI）

## ★ 专项：朱雀「人工为主」协议（v9.6.0）

> **场景**：朱雀结果为「疑似AI 100%」或「疑似 ≥ 人工」。继续同义替换/拆句无效。  
> **含义**：检测器已不认为是「纯 AI 指纹」，但整篇仍缺足够「人工证据」。  
> **误区**：继续让 AI 做表面润色 → 往往仍 100% 疑似，甚至变成「被工具处理过」。

### 判定与目标（先改目标再改稿）

| 项目 | 说明 |
|------|------|
| 现状解读 | 统计层（句长/禁词）可能已部分达标；卡在**内容层唯一性 + 结构不完美 + 人工注入不足** |
| **硬验收目标** | **人工创作特征占比 > 疑似AI创作特征**（人工为主）；AI 创作特征接近 0 或仅为次要残留 |
| 未达标定义 | **疑似 ≥ 人工**（含疑似 100%）→ 禁止称「检测已通过」，必须进入强化轮 |
| 平台差异 | 若发文平台只禁「AI创作」而放行「疑似」，可由用户自判是否发文；**skill 流水线仍按人工为主验收** |
| **语义边界** | **`.done_zhuque` = 4.1e 步骤已登记 ≠ 三态已「人工>疑似」**。闭环判定只认 `.done`；检测达标只认用户回传三态 |

### 突围动作（按优先级；组合执行，禁止只做表面润色）

1. **【人工段注入·P0 硬配额】** 每章 ≥2 段、合计约 ≥300 字口述式重写（真人作者介入更好）：  
   - 真实感官记忆（气味/触感/环境噪音/方言口癖）  
   - 不可被模型「猜中」的具体细节（错位物件、没用的闲笔、角色无关动作）  
   - 不对称信息（没解释完、无关插叙）  
   - 写进正文后**禁止再用 AI 整段重写这些段落**
2. **【段落级重生·P0】** 用朱雀按段检测（`is_merge=false`）：  
   - 连续高疑似段 → **整段删掉重写**（换切入角度/时间线/人物视点），禁止同义词打补丁
3. **【结构不完美·P1】** 打破可预测结构：中段跳时间/跳场景；允许「没解释完」的信息残留；禁止段段总结、段段扣题
4. **【对话人工毛刺·P1】** 主要角色 1～2 个口癖；允许打断、半句、跑题再拉回；对话中夹无关小动作
5. **【写前人工种子·联动 03_06】** 感官锚点≥3 / 无用细节≥2 / 结构不完美≥2 / 低概率表达——**写作时就植入**
6. **【指纹客观线】** `scripts/fingerprint.py`：方差≥90、短句占比入带、对话占比贴近题材；**达标后禁止继续机械拆句**
7. **【禁 AI 改 AI】** 禁止「再让模型把全文润一遍」；修复只针对报告点名段落
8. **【禁过度工具痕迹】** 不用标点游戏/生僻字堆砌刷分；改动必须读起来仍顺

### 人工证据强化轮（疑似 ≥ 人工时）

用户回传朱雀三态，若 **疑似 ≥ 人工**：
1. 人工段注入增至累计 **≥4–6 段**（或全章约 **20–30%** 关键句为高人工特征表达）
2. 继续对高疑似段整段重生
3. 加大结构破坏与对话毛刺
4. 更新审核报告「人工证据包」节
5. 状态回执写明：当前三态 / 已做强化动作 / 是否仍疑似为主 / 下一步
6. **禁止**输出「已完成去AI化 / 检测已通过」

### 章节最小闭环（与流水线对接）

- [ ] 已跑分布+用词+朱雀六指标预检（4.1b–4.1d）
- [ ] 已执行「人工证据包」（4.1e）：**人工段注入（≥2段/约≥300字）** +（如触发）**≥1 段重生** + 结构破坏 + 对话毛刺自查
- [ ] 写入 `[书名]/.done/第NNN章_zhuque.done`（本标记为**章节完成必需**）
- [ ] 对用户回执包含：`写后流水线：已执行 / 未执行` + 朱雀预检三态 + 人工证据包动作 +（如已运行）check-done 结果；**三态与闭环必须分列**

### 对用户回执强制格式（防「写了正文就当写完」）

```text
【第NNN章状态】
正文：已保存
字数：xxxx（通过/未通过）
写后流水线：已执行 / 未执行
朱雀预检：✅/🟡/🔴（指标4/5/6摘要）
人工证据包：已做（列出动作） / 未做
.done 标记：列出已有标记；缺哪些
check-done（如已运行）：通过 / 未通过 / 未运行
朱雀三态：用户回传 / 待检测（禁止写成已过检测）
下一步：允许写N+1 / 禁止写N+1（原因）
```

**未输出上述回执、或缺 `.done_zhuque` / `.done_chapter` → 对外不得称「本章已完成」。**  
**禁止**只贴 `.done` 清单或 check-done exit0 冒充「检测已通过」；对外汇报必须分列流水线与三态。
