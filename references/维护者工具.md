# 维护者工具（冷路径·按需读取）

> 发布包 / 上下文分层压缩 / ADR / 热路径预算守卫 = 维护者与长会话元操作，非每章闭环步骤；从 `modules/00_强制执行协议.md` 写后流水线节迁出，00 只留指针。

**发布包（P3-19）**：`python scripts/package_skill.py --check|--out 路径`（ps1 仅 `-Check`）——校验 SKILL.md frontmatter 三字段并列载荷清单；确定性 zip 仅 py 产出。

**上下文分层压缩（P3-18）**：长会话需压缩时只裁 `layer=compressible` 的文件（合法名单**单源=`scripts/doc-budget.json`** 各文件 `layer` 字段与 `context_layers` 键，现 10 件：5 个按需模块（03_04/03_06/03_13/03_24/03_26）+ 2 个按需规格（03_26B/03_26C）+ 3 个模板（事实台账/卷时间线/修复子代理调用；无阶段模板） → 压成「模块名+一句话当前状态+路径」一行；勿按记忆枚举）；`layer=protected`（SKILL/00/system_prompt/02 索引/任务书与朱雀模板等 7 件）**永不裁**。`check-doc-budget` 双实现逐文件校验，缺一即红。

**决策记录（ADR）**：移植/门禁/记忆系统的规则性决策落 .agents 目录（notes/状态/类别/YYYY-MM-DD-标题.md 两级目录）：problem → decision → validation；**无法写出 validation 的规则不进主路径**。

**热路径预算守卫（可选·维护者/CI 用）**：`python scripts/check-doc-budget.py`（同口径 `scripts/check-doc-budget.ps1`），规则单源 `scripts/doc-budget.json`；度量=去空白字符，文件级预算 + 单次调用路径上限 `path_ceiling.limit`。超预算 exit1 → 删等量旧文本或显式调高预算并写明 why，**禁止静默放宽**。
