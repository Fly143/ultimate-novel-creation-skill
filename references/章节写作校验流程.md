# 章节写作校验流程（03_06 步骤4 执行细节）

> 适用范围：字数校验、人工种子核对、段落长度校验、规划表场景核对。
> 写入时机：03_06 步骤4 主代理接收子代理正文后、移交写后流水线前。

## 一、字数校验（步骤4.3）

脚本：`python -c "import re,sys; t=open(sys.argv[1], encoding='utf-8').read(); print(len(re.findall(r'[\u4e00-\u9fff]', t)))" [正文文件]`

- 低于字下限 → 退回子代理扩写（context 中包含"上一版字数不足，需扩写至{字下限}字以上"）
- 高于字上限 → 退回子代理精简
- 在范围内 → 通过

## 二、人工种子核对（步骤4.7）

按写作要求第8条硬配额逐项通读正文：

| 配额 | 基准（2000-2500字章） | 检查方法 |
|------|---------------------|----------|
| 感官锚点 | ≥3处 | 找气味/触感/声音/环境噪音的具体描写 |
| 无用细节 | ≥2处 | 找不承担推进功能的闲笔/物件 |
| 结构不完美 | ≥2处 | 跳时间/少过渡/未解释信息残留 |
| 低概率表达 | 每500字≥1处 | 非常规比喻或冷门形容 |
| 对话毛刺 | 对话章 | 口癖/打断/半句/夹动作 |

不达标 → 退回子代理**定点补种**（指明缺哪类、建议位置），**禁止**借机全文重写。

## 三、段落长度校验（步骤4.7b·文风硬约束）

**触发条件**：项目文风设定「每段上限句数」字段有具体数值（>0）。

**检查方法**：

```python
import re

# 从文风设定读取上限（示例：文风设定文件路径已知）
with open('[书名]/设定/[书名]_文风设定.md', encoding='utf-8') as f:
    text = f.read()
# 提取「每段上限句数：N」
m = re.search(r'每段上限句数[：:]\s*(\d+)', text)
limit = int(m.group(1)) if m else 0

if limit <= 0:
    print('文风设定未设置每段上限，跳过段落长度校验。')
else:
    paragraphs = [p.strip() for p in content.split('\n') if p.strip()]
    for i, p in enumerate(paragraphs):
        sentences = re.findall(r'[。！？]', p)
        if len(sentences) > limit:
            # 标记为需拆段
            print(f"段落{i+1}: {len(sentences)}句（上限{limit}）— {p[:60]}")
```

**修复方式**：主代理**当场拆段**，不退回子代理。在动作/对话节拍处断开换行。

**拆段原则**：
- 在说话人动作/神态处断开（"刘波说"前或后）
- 在场景切换处断开
- 保留对话完整性（不在引号中间断开）
- 拆完检查：每段仍 ≥1 句，总字数变化 ≤5%

**修复后**：重跑字数脚本确认字数未缩水。

## 四、规划表场景核对（步骤4.7c）

**检查方法**：

1. 读取 `记忆系统/上下文.md` 的「下一章承诺」字段
2. 读取章节规划表本章行的「场景」列
3. 两者不一致时 → **以上下文承诺为准**

**理由**：上下文是派生件（由 state 渲染），规划表可能是上一轮规划时写的旧值，未随后续修订更新。

**处置**：在细纲 CONTEXT 中注明“场景取值：上下文承诺为XX，规划表为YY，以上下文为准”。

## 五、句长方差交付门禁（步骤4.7d·移交流水线前必检）

> 口径与 4.1b 容错带同源：方差 ≥110 达标；90–110 容错带；<90 未达标。先落盘再移交，避免到 4.1b 才打回头。

**检查**（与字数脚本同批执行；正文末尾带 `----` 块时用 `scripts/fingerprint.py --skip-first --stop-at-dashes` 口径）：

```python
import re, statistics
glass = [s.strip() for s in re.split(r'(?<=[。！？……])', content) if s.strip()]
lens = [len(re.findall(r'[一-鿿]', s)) or 1 for s in glass]
print('方差', statistics.pvariance(lens), '句数', len(lens))
```

**项目文风优先（句长禁忌的让位判定）**：

1. 先读 `[书名]/设定/[书名]_文风设定.md` 的句长上限（如「禁止超过 N 字的句子」/「平均句长 A–B 字」）。**有上限且与 40–60 字长句穿插冲突时 → 本节长句穿插不适用**，走第 2、3 条。
2. 改用「超短句（4–9 字）↔ 中长句（上限内）自然交错」拉开句长方差，配合合并碎片段；**禁机械切碎长句凑方差，禁超出项目句长上限**。
3. 修前先跑 `scripts/fingerprint.py` 取**本书章族谱系**（既往 2–3 章：段落数/句子数/段长均值/句长均值/句长方差）作基线；修后「落回族系区间」才算修好，不以单章数字为唯一目标。
4. 停落在容错带（方差 <90 但整章短句主导、形态不像电报体）→ 标 🟡、不阻断，报告加 `note: distribution relaxed for readability (book style caps sentence length)`，照常移交流水线。

**重复残留快扫（移交流水线前必做，正文来自任何来源都要扫）**：子代理成品稿、自动合并产物可能携带重复小句（同段内同款描述连写、相邻段共用起句）——字数与段落脚本只查缩水不查膨胀，重复块能蒙混过关。

- 段内：对每段做 N 字窗口（N=4–8）重复扫描，同段出现 ≥2 次即列候选（排除人称/虚词打头的窗口，如「他/她/这/那/了/的/一/就/是」）。
- 相邻：相邻两段共现的 ≥4 字连续窗口列候选（跨段重复常以换行分隔，只看段内会漏）。
- 候选逐条判读后修：删重复小句或与相邻句合并为一处；每处替换前断言 `content.count(old)==1`，修完重跑字数脚本 + `scripts/fingerprint.py` 确认未膨胀。
- 与 SKILL.md「修复替换防重复」的分工：本条抓**已存正文的存量残留**，那条防**替换操作引入的复制重复**——两条都要跑。

**判定与处置**：
- 方差 ≥110 → 通过

**操作前探测（防「脚本显示完成但零命中」的静默空跑）**：

- 动手前先 `open(path,'rb').read()` 探测行尾符（`\r\n` 还是 `\n`）与段落分隔（空行还是紧邻），脚本的 split 口径必须对齐——行尾不符时全文被当 1 行、合并/替换静默 0 命中（已观测：按 CRLF 处理但文件是 LF，几轮结构调整全部空跑，重扫才发现）。
- 合并/替换前全量预检命中数并 fail-fast：命中数 = 0 的批次立即停下排查，禁止「跑一遍但零改动」当作完成。
- 合并的结果必须写回「最近一段非空段落」的槽位；写进取空行/空段槽位会造成内容重复（字数脚本只查缩水不查膨胀——已观测合并后正文出现整段重复，`count==1` 断言未用）。
- 章内对白段与叙述段交替，相邻叙述段之间隔着对白 → 只合并「两端均无引号、各自 ≤16 字」的段，禁止跨对白边界/引号闭合处合并（会打断说话句子、引号配对错位）。
- 预算记实：方差贡献 ≈ (新句长−句均)²÷句数；句数 >320 且句均 ≤8 字的首版，字数配额内拉长句可能够不到 110——停在 90–110 容错带并如实记录，优先保短句占比/感官锚点/禁用词达标；3 轮仍 <90 → 移交流水线并在回执注明。

- 90–110 → 记 🟡，不阻断，正常移交（交 4.1b 同口径复算）
- **方差 <90（电报体）→ 当场「句法修复轮」（主代理机械操作，不退回子代理）**：
  1. 穿插长句：叙述/环境段、对话标签后、内心活动段插入 15–25 字细节句或 40–60 字插叙句（感官/物件/拖延动作），每 150 字左右 1 处（2400 字章约 16 处）
  2. 合并碎片段：1–2 句的独立短段并入相邻段（动作段/对话段）
  3. 唯一命中断言：每处替换前 `content.count(old)==1`，替换后核对新短语唯一出现（防静默复制重复块——字数/段落脚本不查膨胀）
  4. 修完重算方差；字数超上限则删冗余（**禁为控字数删长句**）
- 一轮后仍 <90 → 再加长句 5 处重算，最多 3 轮；仍不达标 → 移交写后流水线并在回执注明该情况
- **防回落**：流水线内凡删除长短句/增删长句的改动（含 U 意见修复、证据包增删）→ 改完重算方差，跌破 90 立即补 1–2 处 40–60 字动作/细节长句再重算；删除一处长句与新增一处短句会相互抵消方差收益，删除类改动必须补长句
- **源头预防**：写作子代理 context 加一句「长短句交错、避免通篇短句/电报体」指令

## 六、设定文档标点自检（写作子代理注入前）

- 细纲/规划表/档案/约束文档的引号、破折号同样全角（标点红线适用于全部项目文档，不限于正文）
- 细纲写完 → 半角直引号成对替换为 “ ”（代码与正文「标点后处理」同套），复核 `content.count('"')==0` 再注入写作子代理（半角引号源头之一是子代理照搬细纲直引号）
- 正文保存前的半角引号检查仍按 SKILL.md「标点后处理」执行

## 七、复核返修后同步口径（闭环后被返工时必执行）

返工改动正文后（U 意见修复、复核发现返修），改稿者必须同步下列口径，否则指纹/数字/证据包与正文脱节：

1. 重跑 `python scripts/text_guard.py -p [项目绝对路径] -c [章] digest` 刷新指纹；流水线内任何落盘改稿后都得重跑，以最终稿为准。
2. 新字数/段数/方差/指纹同步写入三处：`报告/第NNN章_章节档案.md`、U 报告「4.1d 六指标」节、`报告/第NNN章_朱雀证据包.md`——**段号锚点按最新正文段落号重核**（删段/改段后旧段号全部失效）。
3. `记忆系统/_state.json` 的 `wordcounts` 键为字符串目录（如 `"15": 2725`）；JSON 直改后必须跑 `python scripts/state_render.py --project [项目绝对路径]` 重渲染派生（参数名是 `--project` 不是 `-p`，传 `-p` 报参数错误）。
4. 终次复核报告命名「终版复核」（如 `报告/第NNN章_终版复核.md`）；【第NNN章状态】回执附终版指纹。已闭环的 `.done` 空标记语义不变、无需重标，只更新文档口径。

## 八、待定事项（提案·未启用·未经作者确认不得作为门禁执行）

> 本节仅记录待评审设计，不属于现行门禁/流程。

- **输入侧保真缺口**：写入侧有硬门禁（check-done P0–P6），读取侧无钩子——写作/改大纲/更新角色数据前须读的档案，若子代理未读而凭印象写，设定漂移不可见。
- **候选方案（提案）**：交付物附「读取证明」JSON：每份被读文件声明 `sha256` + 从该文件原文提取的连续子串 `extracts`（≥3 份文件、每条 ≥6 汉字、容忍少量标点差异）+ `read_at` 早于正文 mtime。校验脚本交叉验证（现值哈希一致 + extracts 确为原文连续子串）——幻觉抽取几乎不可能连续命中原文，可显著拦截「没读就凭感觉写」。可并入 check-done 规则集增补 P7 门禁；未实施。
