# 修复子代理调用模板（触发 4.3 修复路径时读取）

> 用法：按 `modules/03_26_功能模块.md` 步骤4.3 触发后，替换占位符 `{工作目录}` `{书名}` `{NNN}` `{skill 目录绝对路径}` 逐字发起 `delegate_task`（`toolsets:["file"]`）。
> 本模板为按需资产：全 PASS 路径不加载（03_26 主文件不再内联此规格，省去每章常载）。

```
goal: 根据审核报告修复第NNN章正文中的问题

context: 中文回复。项目目录：{工作目录}，章节文件：{书名}/正文/第NNN章_章节名.txt。
  
  ★ 关键：你只需读取以下文件，不需要读取记忆文档（圣经/人物弧线/剧情时间线 等）。
  审核报告已经包含了具体段落引用、矛盾点说明和修改建议。

  【必读文件】
  1. {书名}/正文/第NNN章_章节名.txt — 待修复的章节正文（纯净：仅标题行 + 正文，无元数据）
  2. {书名}/报告/第NNN章_全量审核报告.md — 状态为 FAIL 的审核报告
  3. {skill 目录绝对路径}/references/高级写作技巧-整合版.md — 去AI味改写规范（每章必读）
  4. {skill 目录绝对路径}/references/朱雀AIGC检测对策.md — 朱雀六大指标 + 人工为主验收（**每章必读**）
  5. {skill 目录绝对路径}/templates/朱雀去AI化检查清单.md — 人工为主协议检查清单（修复完成后逐项自查）

  【修复要求】
  1. **逐条处理审核报告中的所有标记项**：❌ 需修复（必须修改）、🟡 建议（按"改最少"原则优化——能改一词不改一句、不改剧情功能、不新增内容；无把握的标注 `[需复核]`）
  2. 按审核报告中的「修改建议」执行修复
  3. 只修改有问题的段落，保持其余内容不变
  4. **⚠️ 禁止整段重写报告「人工证据包」节已点名的人工注入段**（可微调标点/明显错字，不得换成模型腔表达）；修复以报告点名段落为界
  5. **反AI腔项**（语言模块化/结构规整/情感薄弱/模板词·高频词/万用副词级联/比喻重复/相邻同构，含 ❌ 与 🟡）：按 `references/高级写作技巧-整合版.md` 第十二节「去AI味改写规范」执行——同时按第十三节「检测器友好改写」执行（打破判断句/总分总、降低刻意复杂度）。**每章必读 `references/朱雀AIGC检测对策.md`，按六大指标逐项对照优化**（特别关注指标4语义连贯性、指标5空洞度、指标6情感修辞三项维度），修复完成后按 `templates/朱雀去AI化检查清单.md` 逐项自查。无反AI腔问题时也执行对照，确保六指标达标（指标1/2/3 已有脚本客观兜底，重点查 4/5/6 主观维度）
     - 改最少效果最大：能改一词不改一句；人名/地名/数字/专有名词优先保留
     - 删除比例分级：轻度 ≤15% / 中度 ≤25% / 重度 ≤35%；不得整段删除剧情功能内容（伏笔/钩子/情绪承接/因果锚点）
     - 保留创作意图：只改"怎么说"不改"说什么"，不新增情节/设定/时间线
     - 疑似或不确切的修改在修复记录中标注 `[需复核]`
     - **结合审核报告「分布检查」节的客观数值打散分布**：句长方差、≤20 字占比、段落长短、对话占比、修饰密度——修复后由主代理重跑 `scripts/fingerprint.py`（或 perl/pwsh 同口径实现）对比真人指纹区间，未落入区间视为未修干净
     - **结合审核报告「用词检查」节的超标词**：按 `references/高级写作技巧-整合版.md` 铁律三分档替换/删减（高危类优先，中频类合计压到 ≤8 处/章）——修复后由主代理重跑 `scripts/wordfreq.byte.pl`，无 ❌ 才算修干净
  6. 修完后覆盖写入原文件：{书名}/正文/第NNN章_章节名.txt
     - 正文文件只含「标题行 + 正文」，**禁止**写入元数据/状态/YAML/分隔线——章级档案由 03_26 步骤6 单独写入 `{书名}/报告/第NNN章_章节档案.md`，与正文分离
     - ⚠️ **旧格式章节**（v9.5.18 之前，正文末尾原有 `----` 元数据块）修复时：**保留原 `----` 块原样不动，只改正文**（该块继续有效，见 README「旧项目兼容」）。不得按上一条禁令删除它；如需转成新格式，由用户显式要求，并同时按本模块步骤6 产出章节档案
  7. 在报告末尾追加修复记录：
    
     ---
     ## 修复记录
     - [YYYY-MM-DD] 修复了以下问题：
       1. [问题简述] @[段落位置]
       2. ...
  
  最后一行返回：FIXED: [N]个问题已修复 或 无法修复: [原因]
```
