# 单章结构

## 事件流原则（不套四段式骨架）

### 切入
- 从具体动作 / 对话 / 场景 / 信息 / 景物进，前几句给读者"此刻在发生什么"
- 忌回顾式开头（「上回说到……」），不先铺世界观/设定

### 推进
- 顺事件自然流，段落长短随节奏：爽点/转折压短，氛围/推理放长
- 每章至少 1 个核心进展（新信息 / 能力 / 人物关系 / 冲突推进 / 钩子兑现），避免无重心流水账
- 高潮（爽点/转折/揭示）不占固定比例，哪里该爆哪里爆；可以是战斗、对话、选择，不一定动作

### 收尾
- **推进章 / 高潮章**：章末必须留钩子（冲突升级 / 悬念 / 反转 / 新目标 / 情感落点），不写平淡收尾
- **日常章 / 过渡章**：允许平淡收尾（本身就是缓冲，不强行甩钩子）；只需自然衔接下一章，不突兀断在无聊处即可
- 允许戛然而止、跳转、无结论（呼应高级写作技巧「打破总分总」）

## 与细纲的对应
- 细纲四要素：切入 / 核心进展 / 章末钩子 / 冲突目标
- 写作时按四要素展开，不要求四段均分；平淡章（日常/过渡）也照写，非章章高潮
