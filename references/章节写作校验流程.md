> 写入时机：03_06 步骤4 主代理接收子代理正文后、移交写后流水线前。

## 一、字数校验（步骤4.3）

脚本：`python -c "import re,sys; t=open(sys.argv[1], encoding='utf-8').read(); print(len(re.findall(r'[\u4e00-\u9fff]', t)))" [正文文件]`

- 低于字下限 → 退回子代理扩写（context 中包含"上一版字数不足，需扩写至{字下限}字以上"）
- 高于字上限 → 退回子代理精简
- 在范围内 → 通过

## 二、人工种子核对（步骤4.7）

按写作要求第8条硬配额逐项通读正文：

| 配额 | 基准（2000-2500字章） | 检查方法 |
|------|---------------------|----------|
| 感官锚点 | ≥3处 | 找气味/触感/声音/环境噪音的具体描写 |
| 无用细节 | ≥2处 | 找不承担推进功能的闲笔/物件 |
| 结构不完美 | ≥2处 | 跳时间/少过渡/未解释信息残留 |
| 低概率表达 | 每500字≥1处 | 非常规比喻或冷门形容 |
| 对话毛刺 | 对话章 | 口癖/打断/半句/夹动作 |

不达标 → 退回子代理**定点补种**（指明缺哪类、建议位置），**禁止**借机全文重写。

## 三、段落长度校验（步骤4.7b·文风硬约束）

**触发条件**：项目文风设定「每段上限句数」字段有具体数值（>0）。

**检查方法**：

```python
import re

# 从文风设定读取上限（示例：文风设定文件路径已知）
with open('[书名]/设定/[书名]_文风设定.md', encoding='utf-8') as f:
    text = f.read()
# 提取「每段上限句数：N」
m = re.search(r'每段上限句数[：:]\s*(\d+)', text)
limit = int(m.group(1)) if m else 0

if limit <= 0:
    print('文风设定未设置每段上限，跳过段落长度校验。')
else:

        sentences = re.findall(r'[。！？]', p)
        if len(sentences) > limit:
            # 标记为需拆段
            print(f"段落{i+1}: {len(sentences)}句（上限{limit}）— {p[:60]}")
```

**修复方式**：主代理**当场拆段**，不退回子代理。在动作/对话节拍处断开换行。

**拆段原则**：
- 在说话人动作/神态处断开（"刘波说"前或后）
- 在场景切换处断开
- 保留对话完整性（不在引号中间断开）
- 拆完检查：每段仍 ≥1 句，总字数变化 ≤5%

**修复后**：重跑字数脚本确认字数未缩水。

## 四、规划表场景核对（步骤4.7c）

**检查方法**：

1. 读取 `记忆系统/上下文.md` 的「下一章承诺」字段
2. 读取章节规划表本章行的「场景」列
3. 两者不一致时 → **以上下文承诺为准**

**理由**：上下文是派生件（由 state 渲染），规划表可能是上一轮规划时写的旧值，未随后续修订更新。

**处置**：在细纲 CONTEXT 中注明"场景取值：上下文承诺为XX，规划表为YY，以上下文为准"。
