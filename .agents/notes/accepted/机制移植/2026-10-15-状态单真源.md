# ADR：状态单真源 + 派生视图（P0-3）

- 状态：accepted
- 类别：记忆系统
- 日期：2026-10-15

## problem

记忆系统五件套（圣经/弧线/时间线/伏笔/台账）是可手改的自然语言文件，多轮写作后互相漂移；无修订历史，手改派生导致的失真无法被发现。

## decision

1. `记忆系统/_state.json` 为唯一权威；五件套+摘要+上下文由 `state_render` 脚本渲染（头含 `derived:state-render` 标记），**派生禁手改**，要改改 state 再 `state_commit commit`。
2. 乐观锁：`.state-commit.lock` + `expected_state_revision` 拒 stale 事务；事务只写项目内 .story 草稿区，成功才删。
3. check 从 state 重渲染并逐字节比对，手改派生即点名 FAIL；旧项目无 `_state.json` → 全流程照旧（`.done` 维持 12 项）。
4. py/ps1 渲染逐字节一致（跨引擎互通回归）。

## validation

- 回归 12 条：手改派生 check FAIL / stale 拒写且事务保留 / 跨引擎互通 2 条（commit `2c802b9`）
- `03_18` 状态单模式总则表 + `03_26` 步骤7 + 00 命令面挂接（commit `dfb6aff`）
